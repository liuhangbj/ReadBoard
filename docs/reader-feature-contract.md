# ReadBoard 阅读器功能契约

本文件以 `61faf5b` 的 Core/Pro 阅读器为功能基准。共享层和 Go 的目标不是“外观相似”，而是除数据网关与产品权限外保持行为等价。

## 迁移门槛

- Core/Pro 根界面在本清单全部通过前不得切换到新的共享壳。
- 共享代码默认承载完整功能；Core 使用本地 gateway，Go 使用远程 gateway。
- 产品差异必须由 capability/permission 显式关闭，不能通过复制后删代码实现。
- 每次迁移至少同时验证 Core/Pro 和 Go；Core 任一既有行为回退即停止迁移。

## 窗口与三栏布局

- 三栏 `NavigationSplitView`：订阅侧栏、文章列表、阅读区结构稳定。
- 左栏宽度允许在 180–360 pt 范围手动调整。
- 中栏宽度允许在 280–640 pt 范围手动调整。
- 右栏随窗口和分栏调整自适应，不因空状态或切换文章重建整套布局。
- 系统侧栏隐藏/显示、窗口缩放和恢复保持可用。

## 左栏资料库与订阅树

- 问题中心状态入口与红/黄/绿状态提示。
- 全部文章、待处理、已导出入口。
- 文章、播客、视频分类入口。
- 所有集合、文件夹、订阅源均显示“未读 / 全部”双计数。
- 大数字紧凑显示，同时保留完整无障碍计数。
- 文件夹展开/折叠，并通过 `sidebar.expandedFolders` 跨启动记忆。
- 文件夹与订阅源选择后正确筛选中栏。
- 添加订阅源、新建文件夹、导入 OPML。
- 文件夹/订阅源右键菜单：刷新、全部已读、重命名、删除。
- 文件夹/订阅源抓取频率和全文模式设置。
- 文件夹/订阅源处理管线开关与历史回填入口。
- 订阅管理、数据看板快捷入口。

## 中栏文章列表

- 标题、来源、日期、摘要、未读状态、评分和处理标签完整显示。
- B 站访问类型等平台标签保持显示。
- 搜索标题与正文，并带防抖和搜索焦点管理。
- 评分上下限、包含未评分。
- 全部/未读/星标筛选。
- 全文、评分、摘要、翻译、转录的完成/未完成筛选。
- 最新/最旧排序。
- 列表密度、摘要行数、来源、日期、未读加粗、日期格式设置。
- 首屏加载、继续加载、查询乱序保护、错误重试和空状态。
- 当前选择高亮，切换文章自动标记已读并同步所有计数。
- 单篇右键菜单：已读、星标、复制/打开原文、处理、删除转录、导出。
- 全部已读操作只作用于当前筛选范围。

## 阅读区

- 右上角星标、已读、分享/后处理、`Aa` 阅读器设置。
- 原文标题链接、来源/作者/日期/评分元信息。
- 全文提取与 AI 评分、摘要、翻译、转录操作。
- 摘要卡片、处理进度与结果反馈。
- 原文/译文视图；所选视图通过 `reading.viewMode` 跨文章和重启记忆。
- 音视频原文/译文/转录稿标签；所选标签通过 `reading.mediaTab` 记忆，并在内容不支持时安全回退。
- Markdown 标题、段落、列表、引用、代码、链接、Frontmatter 和多图正确渲染。
- 音频、YouTube、Bilibili 播放器及播放速度记忆。
- 上一篇/下一篇导航。
- 分享面板：复制链接、复制标题与链接、浏览器打开、触发导出。

## 阅读外观与持久化

- 主题、亮暗模式、正文/标题字体。
- 正文字号、标题字号、元信息字号、摘要字号。
- 行间距、正文宽度、全局界面缩放。
- 元信息展开状态。
- 设置修改立即反映到当前文章，切换文章后不丢失。
- 恢复默认设置。

## 键盘与状态同步

- `J/K` 上一篇/下一篇。
- `S` 星标，空格切换已读，`V` 打开原文。
- `E` 当前范围全部已读，`F` 聚焦搜索，`?` 快捷键帮助。
- 内容更新、处理状态和待处理数量通知后局部刷新。
- 快速切换、后台查询和处理通知不得造成旧结果覆盖新选择。

## 验收方式

- 代码检查：`CoreReaderParityGuardTests` 必须通过。
- 编译检查：Core、Pro、Go 均可独立编译。
- 界面检查：至少验证三栏拖动、双计数、`Aa`、视图记忆、已读回填和一篇图文/音频/视频内容。
- 数据通路：Core 使用本地数据库 gateway；Go 使用远程 gateway，UI/状态模型不分叉。
